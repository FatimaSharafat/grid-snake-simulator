# Grid Snake Simulator

## Overview

A grid-based snake simulation where the snake moves through a grid while managing its energy. The simulation ends when the snake reaches the bottom row or runs out of energy.

---

## Features

- Random movement
- Energy management
- Bonus energy cells
- Grid visualization
- Simulation statistics

---
